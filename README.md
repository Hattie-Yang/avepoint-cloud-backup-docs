# AvePoint Cloud Backup Documentation Portfolio
技术文档个人作品集

## 项目简介
本项目模拟 AvePoint Cloud Backup for Microsoft 365 产品文档开发工作，还原外企技术文档工程师日常工作流程。文档面向海外IT管理员，采用英文原稿优先、中文本地化为辅的写作模式。

## 仓库内容
- 01-quick-start-guide：中英双语快速入门指南
- 02-workflow-diagram：备份还原业务流程图
- 03-terminology-table：中英文统一术语对照表
- 04-qa-checklist：文档质检清单与AI校对记录

## 写作与质检流程
初稿撰写 → 术语核对 → AI辅助润色校对 → QA逐项自检 → 定稿

声明：所有内容为个人练习作品，仅用于求职展示，不用于商业用途。
