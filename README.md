# AvePoint Cloud Backup Documentation Portfolio
技术文档个人作品集

## 项目介绍
模拟 AvePoint Cloud Backup 产品文档开发，复刻外企技术文档工作流程，文档面向海外IT管理员，遵循英文原稿优先、中文本地化的撰写方式。

## 仓库内容
- 01-quick-start-guide：中英双语快速入门指南
- 02-workflow-diagram：业务流程图
- 03-terminology-table：中英文术语对照表
- 04-qa-checklist：文档质检清单、校对记录

## 工作流程
初稿撰写 → 术语核查 → AI辅助校对 → QA自检 → 定稿
